# Git commits

- Use Conventional Commits in English: `type(scope): description` (feat, fix, refactor, chore, docs, test, perf, build, ci, style). Scope is optional; description is lowercase, imperative, no trailing period, under 72 chars.
- Keep commits small and atomic: one logical change per commit. Split unrelated changes into separate commits.
- The commit message is the title line only: no body, and no trailers of any kind (no Co-Authored-By, no Claude-Session, no "Generated with" lines).
- In pull request descriptions, don't add attribution or session links either.
